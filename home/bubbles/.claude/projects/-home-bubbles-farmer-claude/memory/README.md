## What this folder is

Claude Code has a memory feature. With it, the agent can write notes for its future sessions. At the start of each session, Claude Code loads `MEMORY.md` automatically. `MEMORY.md` is a list of the other memory files. In most check-ins, the agent then read the other two files.
