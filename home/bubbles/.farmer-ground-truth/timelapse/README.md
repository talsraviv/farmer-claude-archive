# `/home/bubbles/.farmer-ground-truth/timelapse/`

> **Archive note:** This file was not on the Raspberry Pi. The experimenter added it to the public archive to help you find your way.

**You are in:** the photo archive. It has 795 photos in four folders.

## Why there are four folders

On the Raspberry Pi, all the photos were in this one folder. The first part of each file name showed where the photo came from. In this archive, the experimenter put each type of photo in a separate folder. The file names did not change.

| Folder | Number | Name on the Pi | Who took the photos |
|---|---|---|---|
| [`hourly-camera/`](hourly-camera/) | 568 | `auto_...` | A hidden camera job, one photo each hour. **The agent did not see these photos.** Start here. |
| [`agent-photos/`](agent-photos/) | 184 | `agent_...` | The agent. These are copies of the photos that the agent took and looked at. |
| [`night-check/`](night-check/) | 39 | `night_...` | A hidden camera job, one photo each night at 21:30. |
| [`taken-by-hand/`](taken-by-hand/) | 4 | `manual_...` | The experimenter, by hand. |

## Two views of the same plants

Compare the photos of the agent with the hourly photos from the same time. The agent saw only its own photos. The hourly photos show what the agent did not see.

## Notes

- **Photo size.** Photos from before Aug 26 are 1296 × 972 pixels. Later photos are 2592 × 1944 pixels.
- **Black photos on Sep 6.** A power outage restarted the Raspberry Pi that morning. The lamp stayed off until 13:07.
- **Duplicates removed.** On the Raspberry Pi, the copy job made 991 copies of the agent's photos. 807 of them were exact copies of a photo that was already in the folder. The archive keeps one copy of each different photo.
