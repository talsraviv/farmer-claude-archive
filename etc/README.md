# `/etc/`

> **Archive note:** This file was not on the Raspberry Pi. The experimenter added it to the public archive to help you find your way.

**You are in:** the system settings folder of the Raspberry Pi.

On Linux, the `/etc/` folder contains the settings of the system programs. On the Raspberry Pi, this folder had many files. This archive keeps only one of them: the settings of the web server.

| Folder | What it contains |
|---|---|
| [`nginx/`](nginx/) | The settings of the web server that showed the agent's folder on a public web page. |
